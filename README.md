# pd-bug-bash

Учебное приложение курса «Проектная деятельность» (ПД ТОП-ИТ), пара 12 «Проверка качества и тестирование».

Это запись студентов на консультации. В приложении **намеренно оставлены дефекты**. Ваша задача — найти их и описать так, чтобы автор смог повторить.

## Задание

1. Откройте приложение: https://sink3x.github.io/pd-bug-bash/
2. Прочитайте [USER_STORIES.md](USER_STORIES.md). Это то, как приложение должно работать.
3. За 10 минут найдите как можно больше расхождений с критериями.
4. Каждый дефект оформите по [шаблону](BUG_REPORT_TEMPLATE.md) в листе своей команды.

Подсказка, где искать: пустые значения, слишком длинные значения, границы (последнее место в слоте), повторные нажатия, отмена и обновление страницы, телефон, неожиданный ввод.

## Как засчитывается

| Важность дефекта | Баллы |
|---|---|
| критично | 3 |
| важно | 2 |
| желательно | 1 |

- Дефект засчитан, если по репорту его можно повторить: есть шаги, «ожидали» и «получили».
- Один дефект засчитывается команде один раз.
- +2 балла за подтверждённый дефект, которого нет в ключе преподавателя.

## Запуск без интернета

Скачайте `index.html` и откройте в браузере. Зависимостей нет, данные хранятся в `localStorage`.
