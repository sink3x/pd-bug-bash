# Чек-лист готовности к тестированию (Definition of Done)

Продукт отдаём на проверку, когда отмечены все пункты. Если хотя бы один не отмечен, сначала доделываем.

## Обязательный минимум

- [ ] Главный сценарий проходит от начала до конца.
- [ ] Продукт открывается по ссылке или README без авторов, за 5 минут.
- [ ] Есть тестовый вход и тестовые данные.
- [ ] Известные дефекты уже записаны: тестировщикам не придётся сообщать то, что мы знаем.
- [ ] Журнал решений обновлён.

## Для кода

- [ ] Изменения прошли ревью хотя бы одного участника команды.
- [ ] Тесты, если они есть, проходят.
- [ ] В репозитории нет паролей, токенов и чужих персональных данных.

## Для данных и моделей

- [ ] Синтетические данные помечены как синтетические.
- [ ] Ноутбук запускается сверху вниз без ошибок.
- [ ] Метрика посчитана на отложенной выборке.
