# Шаблон плана тестирования

Заполняет команда-автор до того, как отдаёт продукт на проверку. Одна страница.

## 1. Что проверяем

| Поле | Значение |
|---|---|
| Продукт и версия | название, ссылка или коммит |
| Гипотеза | «если X, то Y изменится с A на B» |
| Главный сценарий | одной фразой: кто, что делает, что получает |
| Что не проверяем сейчас | то, что сознательно вне среза |

## 2. Как открыть без авторов

| Поле | Значение |
|---|---|
| Ссылка или команда запуска | |
| Тестовый вход | логин и пароль тестового пользователя, не настоящего |
| Тестовые данные | где лежат, как загрузить |
| Устройства и браузеры | хотя бы один ноутбук и один телефон |

## 3. Тест-сценарии

На каждую главную историю: хотя бы один позитивный, один негативный и один граничный сценарий.

| 3 | | граничный | | | |

| 5 | | | | | |

Типы: позитивный (всё правильно), негативный (пользователь делает не то), граничный (последнее место, максимум, ноль), повтор (двойное нажатие, повторная отправка).
